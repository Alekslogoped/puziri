# Слова в пузырях

Самостоятельная игра для логопедических занятий: один уровень, пять временных категорий по четыре слова. Возьмите сам пузырь мышью или пальцем, перенесите его и отпустите на подходящем пузыре. Можно свободно двигать пузыри и подбрасывать их: скорость жеста передаётся пузырю. Обычные клики мышью не выделяют и не объединяют пузыри. Для клавиатуры сохранено доступное объединение через Enter / Пробел. Автоматического распознавания речи нет.

## Запуск

Откройте `index.html` непосредственно в браузере или из корня проекта запустите:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте локальный адрес сервера в своём браузере. Сборка, npm и серверная часть игре не нужны. Все пути относительные; внешних библиотек, CDN, хранилища и аналитики нет.

## Словарь

Редактируйте только `config.js`. В демонстрационном наборе компактные пары `[id, text]` превращаются в объекты слов через `.map`. Можно заменить весь `groups` обычным массивом:

```js
groups: [
  { id: 'fruits', title: 'ФРУКТЫ', words: [
    { id: 'apple', text: 'ЯБЛОКО', image: './assets/images/apple.png' },
    { id: 'pear', text: 'ГРУША' }
  ] },
  { id: 'animals', title: 'ЖИВОТНЫЕ', words: [
    { id: 'cat', text: 'КОШКА' },
    { id: 'dog', text: 'СОБАКА' }
  ] }
]
```

Нужно 2–8 групп по 2–4 слова. Все идентификаторы слов уникальны во всём словаре, идентификаторы групп тоже уникальны. Подписи слов — до 14 символов, категорий — до 18. Совпадающие надписи допустимы, принадлежность определяется идентификатором. Выбирайте однозначные категории. Ошибки конфигурации показываются при загрузке.

- `title`: название игры.
- `mode`: `word` или `image-word`. Во втором режиме необязательная картинка отображается над исходным словом; при ошибке загрузки остаётся текст. Для промежуточных пузырей всегда выводятся слова. Изображения: прозрачные PNG/WebP, рекомендуемый размер 512 × 512, поля 8–10%.
- `soundDefault`: по умолчанию `false`. Звуки синтезируются локально после действия пользователя.
- `maxActiveBubbles`: 4–20, по умолчанию 20. В резерв уходят только целые группы, они поступают после ухода категории.
- `moveLimit`: `null` для неограниченных попыток или положительное целое число. Любая проверенная пара тратит один ход; пустое поле не тратит ход.
- `bonusEvery`: каждые N успешных объединений возвращается один ход; по умолчанию 5.
- `scene`: оставьте 1600 × 900. Для портретного контейнера предусмотрена отдельная раскладка с прокруткой.

Отмена восстанавливает состояние до последнего успешного объединения; при лимите также отменяет неверную попытку. Можно отменять во время анимаций и после победы. Перезапуск сохраняет выбранную настройку звука только до закрытия страницы.

## GitHub Pages

Все файлы проекта положите в корень репозитория. В Settings → Pages выберите Deploy from a branch → main → /(root) → Save. Дождитесь публикации и скопируйте **фактический HTTPS-адрес** из Pages. Файл `.nojekyll` уже включён. Локальная проверка не подтверждает публикацию в GitHub Pages.

## Genially

В редакторе: Insert / Вставка → Others / Другие → внешнее содержимое. Вставьте iframe, заменив маркер фактическим опубликованным адресом:

```html
<iframe src="ВСТАВЬТЕ_HTTPS_АДРЕС_GITHUB_PAGES"
  title="Слова в пузырях" width="1280" height="720"
  style="width:100%;height:100%;border:0;display:block;"
  allow="fullscreen" allowfullscreen></iframe>
```

Родительскому контейнеру задайте реальную высоту, предпочтительно 720 или 900 px при формате 16:9. Проверьте в опубликованном Genially клики, перенос при масштабе слайда, звук после нажатия и fullscreen. Полноэкранный режим может запрещаться цепочкой iframe; обычный режим продолжает работать. Игра измеряет собственный контейнер через ResizeObserver и не обращается к DOM родительского сайта.

## Проверки

Браузерные сценарии находятся в `tests/browser.cjs`. Для разработки можно установить Playwright **вне проекта** и использовать системный Chromium:

```sh
npm install --prefix /tmp/bubbles-qa --cache /tmp/npm-cache playwright
node tests/browser.cjs
```

Сервер на порту 8000 должен работать. Альтернативы: `GAME_URL` и `PLAYWRIGHT_PATH` (путь к пакету Playwright). Для игры эти инструменты не нужны. Подробный результат текущей проверки — `VALIDATION.md`.

`assets/cover.png` — отдельная обложка 1600 × 900; она не используется вместо игрового поля. Предметные изображения не включены: базовый режим словесный, авторский словарь и иллюстрации можно добавить позже.

## Морское оформление и анимация

Локальная иллюстрация `assets/images/sea-background.png` используется как фон; её можно заменить своим изображением 16:9 с чистым центром. Если фон не загрузится, остаётся синий градиент. Подписи и кнопки по-прежнему живые HTML-элементы.

Пузыри имеют полупрозрачную заливку, отдельную перламутровую иллюстрацию `assets/images/bubble-pearl.png`, мягкое появление и свечение при объединении. Каждая подпись остаётся целой, в одну строку. В промежуточном пузыре отдельной строкой показывается каждое слово. Радиусы увеличены и учитывают длину подписи; при необходимости размер шрифта подстраивается под доступную ширину. На очень узком экране используется один столбец с прокруткой. Физика рассчитывается с постоянным шагом 1/120 секунды, видимые координаты плавно приближаются к рассчитанным; попадание указателя проверяется по тем же видимым центрам. Собранная категория плавно поднимается. При системной настройке уменьшенного движения декоративные эффекты выключены.

Дополнительная проверка анимации: `node tests/motion.cjs` — сглаживание соседей при слиянии, перенос на движущуюся цель, подъём категории и загрузка морского фона.

## Свободное движение пузырей

Соединение происходит только при отпускании одного пузыря на другом. Соприкосновение от физики или броска не запускает проверку пары. При неправильной паре слова остаются на поле, пузыри краснеют; на свободном поле пузырь остаётся в новом месте и продолжает движение с инерцией. Отмена жеста (pointercancel, потеря окна, resize) возвращает незавершённый перенос. Уменьшенное движение отключает инерционный бросок.

Сценарий `node tests/drag.cjs` проверяет перенос всего пузыря, отсутствие объединения обычными кликами, бросок, сенсорный жест и отсутствие переноса/обрезания слов на пяти размерах экрана.

## Декоративные рыбки

На заднем плане плавают шесть небольших SVG-рыбок. Их маршруты, цвета и размеры заданы в `createFish()` / `updateFish()` в `game.js`; движения тела, хвоста и плавников — в конце `styles.css`. Они не участвуют в игровых столкновениях и не перехватывают указатель. В окне правил движение приостанавливается, на скрытой вкладке расчёт останавливается; при reduced-motion рыбки остаются неподвижными.

Текущий набор: ФРУКТЫ, ОВОЩИ, ЖИВОТНЫЕ, ТРАНСПОРТ и ОДЕЖДА (ШАПКА, ШАРФ, КУРТКА, ПЛАТЬЕ). Все 20 слов появляются сразу. `node tests/default.cjs` проверяет текущий словарь; остальные сценарии используют исходный набор из четырёх групп через `tests/fixture.cjs`, а резерв проверяется отдельно на восьми группах.

Группа ЖИВОТНЫЕ содержит только домашних животных: КОШКА, СОБАКА, КОРОВА, ЛОШАДЬ. Лиса и заяц удалены из игрового словаря.

## Русалочка на финише

После ухода последней категории вместо карточки тем русалочка вплывает слева с вытянутыми руками, останавливается в центре, поворачивает голову к игроку, улыбается и уплывает вправо. Обе руки всё время вытянуты вперёд; махания нет. Между двумя рисованными позами используется плавный переход, плавник слегка движется. Сцена длится около 8 секунд; «Играть ещё» и отмена доступны сразу. Список тем можно посмотреть через счётчик «Группы».

Рисованные иллюстрации: `assets/images/mermaid-swim.png` и `assets/images/mermaid-smile.png`. SVG-обёртка `assets/mermaid.svg` и её встроенная копия в `mermaid.js` размещают изображения и анимируют переход. Все ресурсы локальные. При редактировании SVG обновите и встроенную копию. При reduced-motion вместо перемещения показывается неподвижная русалочка. Проверка полного сценария: `node tests/victory.cjs`.
